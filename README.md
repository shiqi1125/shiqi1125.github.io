# Ethan Miao — Portfolio

Personal portfolio published at https://shiqi1125.github.io/.

## Edit

- `index.html`: introduction, projects, experience, education, and links.
- `styles.css`: responsive page styling.
- `assets/ethan-miao.jpg`: portrait. Replace this file to update the photo.
- `Ethan-Miao-Resume.pdf`: downloadable resume. Replace it to update the resume.

This is a static HTML/CSS website. No build process, login, or backend is required. Project details use native HTML disclosure elements.

GitHub Pages publishes the root of the `main` branch. Commit edits to `main` to update the site.

## Local preview

Run `python3 -m http.server 5187 --bind 127.0.0.1` in this directory and visit http://127.0.0.1:5187/.
