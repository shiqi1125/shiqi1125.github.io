Explore the engineering +

The problem

Make large files reliable to upload, quick to discover, and useful through natural-language queries.

Architecture & decisions

Seven Spring Boot microservices expose 40+ REST APIs behind an AWS Application Load Balancer. S3 multipart uploads and presigned URLs support resumability; Redis locks, checksums, and deduplication coordinate upload state.

Debezium streams PostgreSQL metadata changes into OpenSearch. Kafka retries and dead-letter queues support asynchronous parsing and indexing. A LangGraph RAG agent uses MCP tools for search, metadata lookup, and document retrieval.

Results

Search latency improved by 65% versus indexed SQL queries. The platform sustained 300+ RPS and supported files up to 20 GB without retransmitting completed chunks.
