The problem

Make large files easy to store, find, and reason over through reliable, permission-aware AI workflows.

Architecture & decisions

Seven microservices expose 40+ REST APIs, integrating S3 multipart uploads, Redis distributed locks, and an AWS Application Load Balancer to support 20 GB files and 300+ requests per second.

A hybrid RAG pipeline combines dense vector retrieval, BM25, and cross-encoder reranking with OpenSearch across 1M+ records. A stateful LangGraph agent uses dynamic planning, tool calling, and workflow checkpointing.

File operations are exposed as standardized MCP tools with permission-aware execution, human-in-the-loop approval, and automated recovery.

Results

Recall@5 improved from 72% to 86% over dense-only retrieval. The agent achieved 87% task success on multi-step file discovery, cross-document reasoning, and version comparison. Failure-injection tests recorded 98.5% tool-call success and a 92% recovery rate.

My contribution

Fine-tuned a pretrained plant genomic foundation model using LoRA (r = 16) on attention layers and a regression head, with cosine learning-rate decay while updating under 2% of model weights.

Fused DNA sequence embeddings with 3D structural features using a Graph Attention Network and gated attention. Pearson r improved from 0.71 to 0.77, and prediction MAE decreased by 11.8%.

Evaluation & deployment

Compared frozen, LoRA-tuned, and multimodal models on held-out chromosomes using RMSE and residual error analysis, reducing systematic prediction bias by 16.4%.

Deployed the fine-tuned model on AWS SageMaker with model versioning and CloudWatch monitoring. Optimized model loading and dynamic batching to increase inference throughput by 2.1× at a fixed GPU.
